## Model Utama

| Kelompok | Model aktual | Relasi terkonfirmasi |
| --- | --- | --- |
| Identitas | User, Address, AdminActivityLog | Address/activity log merujuk User; user ID UUID |
| Katalog | Product, ProductVariant, Category, Highlight | Product memiliki Category/Highlight opsional; variant merujuk Product |
| Harga/promo | Discount, PromoCode, PromoUsage | Discount merujuk variant unik; penggunaan promo merujuk user/order/promo |
| Asset/review | Image, Review | Image dapat terkait product/variant/review/category; review merujuk product/reviewer |
| Cart | Cart, CartItem | User opsional dan guest session; item merujuk product/variant |
| Transaksi | Order, OrderItem, OrderAddress, OrderStatusHistory | Order merujuk User; item/alamat snapshot/status merujuk Order |
| Konfigurasi | Setting | Konfigurasi toko |
| AI | AiConversation, AiMessage | Conversation merujuk User; message merujuk conversation |

```text title="Referensi relasi utama"
User -> Address
User -> Order -> OrderItem -> Product / ProductVariant
             -> OrderAddress
             -> OrderStatusHistory
User -> Cart -> CartItem -> Product / ProductVariant
Product -> ProductVariant -> Discount
Product -> Category / Highlight
Product -> Image / Review
User -> AiConversation -> AiMessage
```

Diagram menyederhanakan referensi, bukan ERD seluruh kolom. CartItem unik pada cart/product/variant; OrderItem unik pada order/product/variant. ProductVariant.priceIdr memakai Decimal(10,2), bukan asumsi Product.price integer. Embedding Product memakai unsupported Prisma vector(1024).

## Migrasi

Package menyediakan start:migrate (prisma migrate deploy) dan build (prisma generate). Script migration:generate, migration:run, dan seed tidak ada pada package audit; instruksi generik lama dikoreksi. Seluruh migrasi tetap di repository backend.

<Callout type="warn">
  Tidak dilakukan koneksi database, perubahan schema, migrasi, reset, atau seed. Prosedur operasional lama harus dicocokkan dengan revision backend oleh pemilik layanan sebelum digunakan pada lingkungan nyata.
</Callout>
