## Asal dan Cara Membaca

Snapshot dibaca dari [OpenAPI resmi](https://vi-mamabear-backend.onrender.com/api-json) pada 15 Oktober 2026 (Asia/Jakarta). Inventaris ini dihasilkan ulang dengan `node scripts/docs/generate-api-reference.mjs` dari root repository. Bukti tersimpan di `docs/evidence/api-contract.json`; contoh Swagger dihapus dari snapshot agar tidak menyalin contoh kredensial.

Anotasi bearer adalah metadata OpenAPI. Tidak adanya anotasi bukan bukti endpoint publik; adanya anotasi juga tidak selalu sama dengan guard runtime. Controller auth/cart/payment menunjukkan perbedaan tersebut. Tidak dilakukan pemanggilan endpoint admin atau mutasi untuk menguji akses.
