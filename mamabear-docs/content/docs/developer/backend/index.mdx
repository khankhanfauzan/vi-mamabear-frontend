## Sumber dan Cakupan

Backend tidak ada di workspace frontend. [Source publik pada commit audit](https://github.com/khankhanfauzan/vi-mamabear-backend/tree/811851650796c06d4f4a6f5ca22b833c730385d6) tersedia melalui repository yang dirujuk docs. File dibaca untuk audit; server, test backend, database, migrasi, dan seed tidak dijalankan.

Package mengonfirmasi NestJS 11, TypeScript, Prisma 7 dan adapter PostgreSQL. Schema memakai PostgreSQL dan embedding vector(1024) pada Product. Modul mencakup auth/users, products/variants/reviews, category/highlights, cart/promo, order/payment, shipping/addresses, upload/Cloudinary, reports/settings/activity log, dan AI/search/embeddings. Package juga memuat Midtrans, Cloudinary, OpenRouter SDK, serta mailer.

<Callout type="info">
  Hash source belum dapat dicocokkan dengan deployment Render. OpenAPI publik dan GET katalog/error diamati terpisah pada 15 Oktober 2026. Response Swagger belum lengkap; metadata tanpa guard tidak membuktikan endpoint admin publik.
</Callout>

## Menjalankan pada Repository Backend

Script terkonfirmasi: start:dev, start:debug, build (prisma generate lalu nest build), start:prod, start:migrate, test, test:e2e, dan test:cov. start:migrate menjalankan prisma migrate deploy sebelum start. Audit ini tidak menjalankan operasi tersebut.

Gunakan .env.example backend pada revision yang digunakan tanpa menyalin nilainya ke docs. Source main.ts memakai PORT atau fallback 3000; jangan mengasumsikan port 3001. Script seed tidak ditemukan pada package audit walaupun konfigurasi Prisma mencantumkan entri seed. Instruksi npm run seed lama harus diverifikasi dengan pemilik backend.
