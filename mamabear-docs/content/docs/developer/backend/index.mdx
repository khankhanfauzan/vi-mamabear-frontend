MamaBear Backend adalah layanan RESTful API yang menangani manajemen katalog produk, autentikasi pelanggan & admin, keranjang belanja, checkout transaksi, dan webhook pembayaran.

Bagian ini merupakan dokumentasi teknis internal khusus untuk developer MamaBear.

## Informasi Repositori & Server

- **Repository**: [GitHub vi-mamabear-backend](https://github.com/khankhanfauzan/vi-mamabear-backend)
- **Base URL (Production)**: `https://vi-mamabear-backend.onrender.com/api`
- **Deployment Platform**: Render Web Service
- **Arsitektur Utama**: REST API dengan format respon JSON seragam

<Callout type="info">
  Aplikasi frontend MamaBear mem-proxy permintaan `/api/backend/*` langsung ke server backend production di Render.
</Callout>
