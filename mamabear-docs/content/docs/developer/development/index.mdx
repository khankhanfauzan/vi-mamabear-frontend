## Alur Kerja

1. Ikuti [Setup Lokal](/docs/developer/frontend/setup-lokal) dengan npm/lockfile masing-masing aplikasi.
2. Baca [SOP](/docs/developer/panduan-dokumentasi) sebelum menambah MDX/asset.
3. Daftarkan halaman pada meta.json, lalu jalankan validator, lint, type check, dan build.
4. Periksa route dengan/tanpa sesi, internal link, screenshot, dan responsive.
5. Tinjau [Deployment](/docs/developer/development/deployment) dan hasil QA sebelum rilis.
