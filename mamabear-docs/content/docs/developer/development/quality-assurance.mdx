## Smoke Test Docs

Server production docs dijalankan lokal dengan password/salt uji acak yang tidak disimpan. Pemeriksaan mencakup seluruh 28 halaman developer dengan HTTP 200 dan judul render, User Guide publik, redirect developer tanpa sesi, penolakan markdown/OG tanpa sesi, login salah/benar, Basic Auth, search publik/private, LLM publik, delapan asset image pada audit awal, dan logout.

Chromium memeriksa galeri desktop, UI docs pada viewport 390 piksel, dan referensi API dengan 38 tab. Semua gambar galeri ter-load tanpa broken image; UI docs mobile tidak overflow horizontal pada pengukuran. Interaksi tab request/response diuji. Manifest hasil tersimpan pada docs/evidence/docs-smoke.json; server log dipakai untuk mendeteksi runtime error.

Pemeriksaan pertama pada build sebelum perbaikan await melaporkan unhandled async authorization pada handler markdown/OG. Source diperbaiki untuk menunggu hasil helper. Pemeriksaan berikutnya menemukan fallback static handler tidak dapat membaca request headers untuk otorisasi dan mengembalikan 500; handler markdown/OG diubah menjadi force-dynamic agar pemeriksaan akses berlangsung per request. Build dan smoke test final dijalankan ulang setelah perubahan ini.

## Masalah Existing

Empat test gagal berada di `src/features/cart/hooks/useCart.test.ts`: subtotal, promo valid/tidak valid, dan progress free shipping. Mock service belum mengikuti alur promo API. Fixture pada use-cart-store.test.ts menyebabkan tsc CLI gagal. Source/test bisnis terkait tidak diubah dalam pekerjaan docs.

Build docs memberi warning CSS pseudo-element highlight, cache dependency dinamis Fumadocs, dan metadataBase yang belum ditetapkan. Warning dan konfigurasi hosting perlu ditinjau pemilik aplikasi; validasi tidak dinonaktifkan. TypeScript docs dipin ke 5.9.3 karena TypeScript 7 branch sumber ditolak typescript-eslint existing; tidak ada upgrade dependency runtime massal.

## Menjalankan Ulang

```bash title="Root repository"
npm run docs:validate --prefix mamabear-docs
npm run lint --prefix mamabear-docs
npm run types:check --prefix mamabear-docs
npm run build --prefix mamabear-docs
```

Untuk smoke browser, set DOCS_CHROMIUM_PATH menuju executable Chromium lokal, lalu:

```bash title="Root repository"
node scripts/docs/smoke-docs.mjs
```

Script memakai port 3011 secara default, server miliknya sendiri, profil Chromium baru, dan kredensial lokal acak; tidak memakai password/sesi produksi. DOCS_SMOKE_PORT dapat memilih port alternatif. Hasil API dan capture berada di docs/evidence; tidak ditempatkan pada public asset.

## Kesiapan dan Batas

Dokumentasi siap direview dan diuji pada preview setelah pemeriksaan final lolos. Rilis seluruh aplikasi belum dapat dinyatakan bebas masalah karena tsc/test toko masih gagal dan konfigurasi hosting belum diverifikasi. Deployment produksi tidak dijalankan.

Tidak dilakukan login pelanggan, transaksi/payment, upload produksi, mutasi database, seluruh role admin, atau evaluasi kualitas AI. Source backend belum dicocokkan dengan hash deployment; response Swagger yang kosong tidak diisi data buatan. Screenshot hanya membuktikan tampilan pada waktu capture.
