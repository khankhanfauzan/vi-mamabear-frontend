## Struktur Direktori

```text title="Struktur checkout"
src/
  app/
    (auth)/           login, register, forgot-password, auth/verify-email, auth/reset-password
    (shop)/           products, categories, search, cart, checkout, account
    admin/            dashboard, products, categories, orders, promos, users, customers, reports, settings
    api/auth/         handler NextAuth
  features/           account, address, admin, ai, auth, cart, categories, checkout, home, orders, products
  components/layout/  Navbar, Footer, ChatWidget, navigasi akun/admin
  components/ui/      komponen shared Radix/shadcn
  lib/                api.ts, auth.ts, config.ts, helper
  providers/          AuthProvider.tsx
  store/              use-ui-store.ts
  types/              tipe bersama, NextAuth, OpenAPI
mamabear-docs/        aplikasi Next.js/Fumadocs terpisah
public/               asset statis toko
```

Modul menggunakan components/hooks/services/types sesuai kebutuhan. Tidak ada folder `products/api`. Hook katalog aktif didefinisikan dalam `ProductCatalogClient.tsx`; `hooks/useProductList.ts` pada checkout audit kosong.

## Route dan Navigasi

Route group `(shop)`/`(auth)` tidak masuk URL. `components/layout/navigation` berisi TopNavbar, BottomNavbar, SidebarMenu, dan UserDropdown. Akun memakai AccountSidebar; shell admin ada di `layout/admin-navigation`.

| URL | File di src/app | Akses menurut kode |
| --- | --- | --- |
| `/` | `page.tsx` | Publik; force-dynamic |
| `/products`, `/products/[slug]` | `(shop)/products` | Publik |
| `/categories`, `/categories/[slug]` | `(shop)/categories` | Publik |
| `/search?q=...` | `(shop)/search/page.tsx` | Publik |
| `/cart` | `(shop)/cart/page.tsx` | Tidak masuk matcher middleware |
| `/checkout`, `/checkout/payment/[id]` | `(shop)/checkout` | Sesi dicek pada server page; redirect login tanpa access token |
| `/account/**` | `(shop)/account` | Middleware mensyaratkan sesi |
| `/admin/**` | `admin` | Middleware mensyaratkan ADMIN/SUPERADMIN |
| `/login`, `/register`, `/forgot-password` | `(auth)` | Form publik |
| `/api/auth/[...nextauth]` | `api/auth/[...nextauth]/route.ts` | Handler NextAuth, berbeda dari API auth backend |

Matcher toko juga memuat `/dashboard/**`, tetapi page dashboard publik tersebut tidak ditemukan. Docs dilindungi proxy aplikasi docs sendiri.

## Server dan Client

`src/app/page.tsx` meminta empat produk. Detail page mengambil detail/related melalui Promise.all dan meneruskan ke ProductDetailClient di dalam Suspense. State interaktif dan query varian dikelola client. Root layout membungkus AuthProvider dan menjalankan CartInitializer.

Seluruh exception pada detail, termasuk error related products, dipetakan ke `notFound()`. Karena itu 404 UI tidak selalu membuktikan produk tidak ada.

## Sumber Fumadocs

`mamabear-docs/lib/source.ts` memakai defineDocs dari fumadocs-mdx/macro untuk `content/docs`, schema page/meta, dan loader base URL `/docs`. Konfigurasi MDX ada pada next.config.mjs docs. Catch-all developer menambahkan slug developer; section-tree memisahkan sidebar user/developer. Urutan mengikuti meta.json.

Root next.config.mjs meneruskan `/docs`, `/docs/**`, `/docs-assets/_next/**`, dan `/api/search` ke DOCS_APP_URL. Proteksi tetap pada aplikasi docs. Rewrite `/api/backend/**` existing masih Railway; service berbasis API_BASE_URL mengikuti NEXT_PUBLIC_API_URL.
