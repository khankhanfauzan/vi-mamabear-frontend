MamaBear Frontend adalah aplikasi e-commerce modern yang melayani pelanggan dalam memilih dan membeli produk kehamilan, persalinan, dan menyusui, serta menyediakan kanal konsultasi interaktif melalui MamaBear Care.

Aplikasi ini dibangun menggunakan ekosistem **Next.js App Router** dengan pendekatan arsitektur berbasis fitur (*feature-driven*).

## Informasi Repositori & Stack Teknologi

- **Framework**: Next.js 14 (App Router)
- **Bahasa**: TypeScript (Strict Mode)
- **Komponen UI**: shadcn/ui berbasis Radix UI Primitives
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Klien API**: `openapi-fetch` + tipe otomatis dari OpenAPI Backend
- **Autentikasi**: NextAuth.js (JWT Session)
- **Dokumentasi Terintegrasi**: Next.js 16 + Fumadocs di subfolder `mamabear-docs/`

<Callout type="info">
  Situs dokumentasi yang sedang Anda baca ini merupakan aplikasi Next.js terpisah di folder `mamabear-docs`, yang di-deploy ke Vercel dan di-proxy di jalur `/docs`.
</Callout>
