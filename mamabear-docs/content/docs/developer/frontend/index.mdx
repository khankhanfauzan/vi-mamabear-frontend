## Stack dan Batas Verifikasi

Toko: Next.js `14.2.35`, React 18, TypeScript strict, Tailwind CSS 3, Zustand 5, NextAuth 4, React Hook Form, Radix UI, dan Sonner. Aplikasi `mamabear-docs` memakai package/lockfile terpisah dengan Next.js 16, React 19, dan Fumadocs.

<Callout type="warn">
  Request aktif memakai native fetch dan wrapper `src/lib/api.ts`. Package openapi-fetch dan tipe OpenAPI tersedia, tetapi createClient pada wrapper dikomentari. Jangan mengklaim seluruh request tervalidasi otomatis terhadap OpenAPI.
</Callout>

| Modul | Implementasi | Status bukti |
| --- | --- | --- |
| Homepage | `src/app/page.tsx`, `features/home` | Source dan screenshot deployment |
| Produk/kategori/search | `features/products`, `features/categories` | Source dan halaman publik diamati |
| Auth | `features/auth`, `lib/auth.ts` | Source; login pelanggan belum dijalankan |
| Cart | `features/cart` | Source, test existing, dan screenshot keranjang |
| Checkout/order | `features/checkout`, `features/orders` | Source; tidak membuat transaksi/pembayaran |
| Alamat/ongkir/akun | `features/address`, `features/account` | Source dan screenshot akun; alamat/ongkir belum diuji |
| Admin | `features/admin` | Source; dashboard internal tidak difoto |
| AI | `features/ai`, `components/layout/ChatWidget.tsx` | Source; riwayat memiliki fallback mock berflag isMock |

Path features/lib pada tabel relatif terhadap `src`.
