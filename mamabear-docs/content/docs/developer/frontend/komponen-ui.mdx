## Komponen Shared

`src/components/ui` memuat button, dialog, input, label, checkbox, badge, card, alert, dropdown-menu, carousel, chart, skeleton, spinner, dan sonner. Komponen menggunakan Radix UI, class-variance-authority, helper cn, dan utility Tailwind. Tidak ditemukan sheet.tsx; mini cart ada di `src/features/cart/components/MiniCartDropdown.tsx`.

| Tujuan | Implementasi | Alur dan feedback |
| --- | --- | --- |
| Aksi | ui/button.tsx | Varian cva dan asChild memakai Slot.Root Radix |
| Dialog | ui/dialog.tsx, products/components/shared/AddToCartModal.tsx | Pemilihan produk/varian; error ditangani alur cart |
| Kartu | products/components/shared/ProductCard.tsx | Data katalog, harga, tautan detail |
| Loading | ProductSkeletonCard, detail loading.tsx, ui/spinner.tsx | Membedakan loading dari daftar kosong |
| Notifikasi | Sonner dan hook cart | Toast sukses/gagal; tidak menggantikan validasi backend |
| Navigasi | components/layout/navigation | Pencarian, menu, akun, navigasi mobile |

Path pada tabel relatif terhadap src/features atau src/components sesuai modul.

## Styling

Token ada di `src/app/globals.css` dan tailwind.config.ts. Class semantik berdampingan dengan CSS variable MamaBear. Font toko: Geist lokal dan Quicksand dari next/font/google. Docs mempunyai stylesheet, Tailwind 4, dan font sendiri; konfigurasi tidak digabungkan dengan Tailwind 3 toko.

HeroSection memakai carousel. Highlight menggunakan grid dua kolom dan empat kolom pada md; panel gambar newsletter hidden md:block; shell admin memakai padding sidebar pada lg.

## Responsive yang Diamati

Homepage diuji pada 1440 x 1000 dan 390 x 844. Pada viewport mobile, scrollWidth dokumen sama dengan 390 sehingga tidak ada overflow horizontal pada pengukuran tersebut. Seluruh halaman/breakpoint dan aksesibilitas keyboard/pembaca layar belum diaudit menyeluruh.
