## Prasyarat

Gunakan npm dan package-lock.json masing-masing aplikasi. Toko dan docs mempunyai dependency/engine berbeda; audit menggunakan Node 22. Jangan memakai batas minimum Next.js 14 untuk aplikasi Next.js 16.

<Steps>
  <Step>

### Instal Toko

```bash title="Terminal root repository"
npm ci
```

  </Step>
  <Step>

### Siapkan Environment

Salin .env.example ke .env.local. Template root memuat deklarasi berulang dan contoh secret yang tidak boleh dipakai untuk deployment. Tetapkan satu nilai per variabel pada file lokal.

| Variabel | Penggunaan |
| --- | --- |
| NEXT_PUBLIC_API_URL | URL backend termasuk /api; terlihat browser |
| NEXTAUTH_SECRET | Secret acak sisi server; tanpa prefix publik |
| NEXTAUTH_URL | URL toko lokal/deployment |
| DOCS_APP_URL | URL docs, misalnya http://localhost:3001 |

Jangan commit file env atau menyalin nilai secret ke MDX.

  </Step>
  <Step>

### Jalankan Toko

```bash title="Terminal root"
npm run dev
```

Script menjalankan lint sebelum Next dev. Port default 3000. Di PowerShell yang memblokir npm.ps1, gunakan npm.cmd/npx.cmd tanpa mengubah execution policy sistem.

  </Step>
  <Step>

### Jalankan Docs

```bash title="Terminal kedua"
cd mamabear-docs
npm ci
npm run dev -- --port 3001
```

Salin .env.example docs ke .env.local dan isi DOCS_PASSWORD lokal serta DOCS_SESSION_SECRET. DOCS_USER dipakai fallback Basic Auth. Login di /docs/login tidak memakai akun NextAuth toko. Tanpa DOCS_PASSWORD, Developer Guide ditolak.

  </Step>
</Steps>
