## State

| State | File | Persistensi |
| --- | --- | --- |
| Cart/items/loading/mini cart | `src/features/cart/store/use-cart-store.ts` | Zustand persist mamabear-cart-storage; hanya cart/items di localStorage |
| Sidebar/modal/animasi | `src/store/use-ui-store.ts` | Memori |
| Sesi | `src/providers/AuthProvider.tsx`, `src/lib/auth.ts` | NextAuth provider dan cookie |
| Filter/cursor | `ProductCatalogClient.tsx` | State React dan URL |
| Varian | `useProductDetail.ts` | State dan query variant |
| Pencarian | `useProductSearch.ts` | recentSearches localStorage; lima entri unik |
| Newsletter | `useNewsletterPopup.ts` | newsletter-dismissed; submit belum terhubung API |

Cart meminta backend sebelum memperbarui item lokal. initializeCart membersihkan cache ketika cart tidak ada; kegagalan request dicatat dan loading dihentikan. Event storage melakukan rehydration lintas tab. Persistensi ini tidak membuktikan dukungan mutasi offline.

## HTTP Request

API_BASE_URL berasal dari NEXT_PUBLIC_API_URL dengan fallback `http://localhost:3000/api`. Produk/kategori memakai native fetch, termasuk pada server. fetchWrapper client membaca getSession, menambahkan bearer jika tersedia, mempertahankan opsi request, dan menambahkan Content-Type JSON untuk body string. apiClient menyediakan get/post/put/patch/delete/postImage; FormData tetap menggunakan boundary browser.

```ts title="Pemanggilan existing pada cartService.ts"
const res = await apiClient.post('/cart/items', payload, {
  credentials: 'include',
});
```

Wrapper mengembalikan Response asli. Service bertanggung jawab memeriksa res.ok, payload success, JSON, dan error. Tidak ada retry atau normalisasi error global di wrapper. Request server private memakai sesi server dan bearer eksplisit, bukan helper getSession client.

## Envelope dan Tipe

Response publik teramati memakai success/statusCode/message/data/timestamp. message berupa array, sementara `src/types/api.types.ts` mendefinisikan string. Cursor publik dapat berupa angka, meski beberapa tipe frontend menyatakan string. Type assertion tidak memvalidasi JSON runtime.

fetchFilteredProducts membuka response.data menjadi objek daftar/pagination. Hook search membaca response.data.data. Parser cart menerima envelope atau payload mentah, status 204, dan error non-JSON. Normalisasi belum seragam antarservice.

## OpenAPI

`src/types/openapi/api.d.ts` adalah hasil generator. Script generate:api masih membaca Railway, bukan Render. openapi-fetch terpasang tetapi konfigurasi createClient di wrapper dikomentari. Tinjau perbedaan kontrak sebelum regenerasi.
