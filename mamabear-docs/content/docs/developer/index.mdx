## Tujuan Proyek

MamaBear adalah e-commerce kebutuhan ibu pada masa kehamilan, persalinan, menyusui, dan perawatan setelah melahirkan. Frontend menghubungkan katalog, pencarian, keranjang, checkout, akun, administrasi, dan percakapan dengan layanan backend. Kode memisahkan UI, state, dan komunikasi data menurut fitur.

<Callout type="info">
  Audit: 15 Oktober 2026 (Asia/Jakarta). Status tersedia di source, tercantum di OpenAPI, dan diamati pada deployment dibedakan. Screenshot membuktikan tampilan saat capture; transaksi, pembayaran, dan akun pelanggan belum diuji end-to-end.
</Callout>

## Arsitektur Sistem

```text title="Komponen MamaBear"
Browser
  +-- Toko Next.js 14: src/app dan src/features
  |     +-- Server Component -> native fetch -> REST API /api
  |     +-- Client -> service -> apiClient/native fetch -> REST API
  |     +-- NextAuth -> backend /auth/login dan /auth/refresh
  +-- /docs -> rewrite -> mamabear-docs (Next.js 16/Fumadocs)
        +-- /docs/user: publik
        +-- /docs/developer: login internal atau HTTP Basic Auth
Backend NestJS -> Controller -> Service/Repository -> Prisma -> PostgreSQL
```
