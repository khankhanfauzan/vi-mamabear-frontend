---
title: Chat MamaBear Care
description: Cara bertanya lewat asisten chat di situs.
---

Widget chat ada di pojok bawah halaman toko. Buka, lalu tulis pertanyaan tentang produk atau kebutuhan Mama.

Chat meminta login sebelum percakapan dimulai. Pesan punya batas panjang. Saat jawaban sedang diproses, tombol kirim tidak bisa dipakai lagi.

Jika jawaban memuat nomor WhatsApp MamaBear, nomor itu menjadi tombol **Chat via WhatsApp**. Tombol itu membuka percakapan WhatsApp di tab baru.
