Selamat datang di **MamaBear** 🐻💕 — toko online pilihan untuk kebutuhan Mama sejak kehamilan, persalinan, menyusui, hingga perawatan si Kecil.

![Halaman utama MamaBear dengan banner produk dan navigasi kategori](/docs/frontend/mamabear-homepage.webp)

## Apa yang Bisa Mama Lakukan di MamaBear?

| Fitur | Keterangan |
|-------|-----------|
| 🛍️ **Belanja** | Jelajahi ribuan produk pilihan untuk Mama dan Bayi |
| 🔍 **Cari Produk** | Cari dengan nama atau gunakan filter kategori dan harga |
| 🛒 **Keranjang** | Simpan produk pilihan, terapkan kode promo |
| 📦 **Checkout** | Kirim ke alamat tersimpan dengan kalkulasi ongkir otomatis |
| 👤 **Akun** | Lacak pesanan dan simpan alamat pengiriman |
| 💬 **MamaBear Care** | Tanya AI asisten produk langsung dari situs |
